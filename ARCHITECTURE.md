# Chromium Activity Lab architecture

`extension/background.js` is the Manifest V3 service worker. It owns the Activity Manager, report registry, tab lifecycle, selection, settings, local presence intent, and optional Discord publisher. It restores installed Activity scripts from local storage at worker start and on extension install or update.

An installed Activity has validated metadata and a bundled V1 script stored locally. The manager registers it through `chrome.userScripts` in a separate `USER_SCRIPT` world, with messaging enabled for that world. Activity reports arrive through `chrome.runtime.onUserScriptMessage`; page execution uses document-targeted `userScripts.execute()` in `MAIN`. The manager checks the sending world, tab, frame, document, URL, report schema, rate, and declared network patterns before accepting requests. Retired documents cannot clear newer reports.

The Library in `extension/activities.*` provides Discover, Installed, Updates, local file loading, and Developer diagnostics. It requests declared HTTPS origins as optional host permissions at install time. `extension/popup.*` shows the selected playback and final local presence intent. The shared V1 contract lives in `schemas/`, `extension/core/activity-contract.generated.js`, and the local `ChudPresence-Activities/` checkout; `npm run check` compares them.

There are no packaged provider content scripts in the lab manifest. `extension/default-activities/youtube/` contains the YouTube Activity installed by default once user scripts are available. A stored removal decision prevents automatic reinstallation. The manifest declares YouTube host access so this first install needs no separate site permission prompt; removing the Activity unregisters its script and deletes its stored code. `extension/core/activity-registry.js` ties reports to tab, frame, and document and selects the latest live frame. `extension/core/presence.js` turns the selected report into a transport-neutral intent. Discord authorization and publishing remain separate in `extension/discord/` and `extension/platform/`.
